# 肉丝生日网站设计说明

## 核心概念

网站是一张会动的生日手账，主角是 CC 和肉丝的两张大头贴。视觉以纸张白、草莓粉、苹果红、鼠尾草绿和少量薰衣草紫组成，保留照片原本的苹果、星星与双丸子头元素，不生成或替换人物形象。

## 页面结构

1. 首屏以“肉丝，生日快乐！”为唯一主标题，两张大头贴从画面两侧进入，在轻微呼吸与漂浮中彼此靠近。主按钮“拆开 CC 的信”平滑滚动到信件。
2. 信件区完整呈现用户指定的《油炸绿番茄》引文和生日祝福。段落随滚动逐一显现，重点语句以手写荧光笔效果标记。
3. 陪伴区用三张不嵌套的便签表达“一起笑、互相托底、一直并肩”，承接引文而不添加虚构经历。
4. 结尾是一只小蛋糕与可点击蜡烛。点击“一起吹蜡烛”后火焰熄灭、祝福出现、彩纸从页面顶部落下；可再次点击重放。

## 动效与适配

- 两张照片使用不同相位的漂浮、摆动和靠近动画，触摸或悬停时会短暂歪头。
- 页面载入、滚动显现和吹蜡烛动效均尊重 `prefers-reduced-motion`。
- 桌面端为左右构图，移动端改为错位叠放并缩小标题，保证无横向溢出。
- 所有交互使用语义化按钮、可见焦点和屏幕阅读器状态文本。

## 验收标准

- 两张照片都清晰可见且持续有轻柔动效。
- 用户提供的中文文案逐字保留。
- “拆信”和“吹蜡烛”都可通过鼠标、触摸和键盘使用。
- 360px 手机与 1440px 桌面均无裁切、遮挡或横向滚动。
- 静态资源使用相对路径，可直接由 GitHub Pages 托管。
